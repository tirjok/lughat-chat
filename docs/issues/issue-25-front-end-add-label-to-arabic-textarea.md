## What to build

Add a `<label>` element associated with the Arabic textarea in ArabicTextarea.vue. Currently, the input relies solely on a placeholder for its label — placeholders disappear when the user types and are not announced by screen readers as labels.

## Acceptance criteria

- [ ] A `<label>` element is added with `for` attribute matching the textarea's `id`
- [ ] Label text describes the input purpose (e.g., "Enter text to convert to speech")
- [ ] Label is visually styled to match the existing design system
- [ ] Screen readers announce the label when the textarea receives focus

## Blocked by

None - can start immediately
