## What to build

Add `autocomplete` attributes to the select and range inputs in index.vue. Without autocomplete hints, browsers cannot provide intelligent suggestions or autofill, which degrades the user experience — especially for users who rely on browser autofill features.

## Acceptance criteria

- [ ] Voice select input has appropriate `autocomplete` attribute (e.g., `autocomplete="off"` if no standard value applies)
- [ ] Speed range input has appropriate `autocomplete` attribute (e.g., `autocomplete="off"`)
- [ ] No visual or layout changes

None - can start immediately
