## What to build

Add `aria-live="polite"` to the ToastNotification component so that screen readers announce toast messages when they appear, rather than requiring the user to navigate to them.

## Acceptance criteria

- [ ] ToastNotification root element has `aria-live="polite"`
- [ ] Toast messages are announced by screen readers when they appear (after current speech completes)
- [ ] No visual or layout changes

## Blocked by

None - can start immediately
